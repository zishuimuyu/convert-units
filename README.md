## 性能指标

经过优化，单位转换库的性能指标如下：

- **单线程性能**：每秒可执行超过570万次单位转换
- **平均转换时间**：每次转换约0.18微秒
- **并发性能**：16线程环境下每秒可执行超过410万次转换
- **内存效率**：使用不可变对象和无状态设计，减少内存开销
- **线程安全**：所有服务实现都是线程安全的
