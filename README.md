# convert-units-java 单位转换SDK

一个高性能的Java单位转换库，支持多种单位类型的高精度转换。

## 功能特性

- **高性能**：单线程每秒570万+次转换，并发16线程每秒410万+次转换
- **高精度**：使用BigDecimal进行计算，支持自定义精度
- **多单位类型**：支持28种测量类型，220+个单位
- **易于使用**：简洁的API设计，支持链式调用
- **Spring集成**：开箱即用的Spring Boot Starter

## 快速开始

### Maven依赖

```xml
<dependency>
    <groupId>com.zishuimuyu</groupId>
    <artifactId>convert-units</artifactId>
    <version>2.0.0</version>
</dependency>
```

### 基本使用

```java
// 基础转换
UnitConversionService service = new UnitConversionServiceImpl();
ConvertResult result = service.convert(UnitEnum.M, UnitEnum.KM, BigDecimal.valueOf(1000));
System.out.println(result.getValue()); // 输出: 1

// 使用构建器
ConvertResult result = ConversionBuilder.create()
    .from(UnitEnum.KG)
    .to(UnitEnum.G)
    .value("1000")
    .build()
    .convert();
```

## 性能指标

经过优化，单位转换库的性能指标如下：

- **单线程性能**：每秒可执行超过570万次单位转换
- **平均转换时间**：每次转换约0.18微秒
- **并发性能**：16线程环境下每秒可执行超过410万次转换
- **内存效率**：使用不可变对象和无状态设计，减少内存开销
- **线程安全**：所有服务实现都是线程安全的
